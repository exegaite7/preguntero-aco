# Preguntero ACO · 2º parcial

Práctica de preguntas multiple choice de **Arquitectura de Computadoras (ACO, UTN FRC)** para el 2º parcial: Unidad 3 (arquitectura), Unidad 4 (assembler 8086) y Unidad 5 (memorias).

- 674 preguntas sacadas de parciales y cuestionarios anteriores (incluye los cuestionarios de Nico y los 2º parciales que tomaron este año), cada una con la cantidad de veces que apareció.
- Filtros combinables: Unidad 3, Unidad 4, Unidad 5, Assembler, "Las que más se repiten", "Cuestionarios Nico" y "El que tomaron".
- Una pregunta por pantalla, con corrección al instante y explicación. Las preguntas de relacionar se responden con desplegables y las de completar texto se arrastran a los huecos.
- Repaso de errores y progreso guardado en el navegador.

Cada respuesta indica su origen: **oficial** (Moodle), **según el apunte** (resuelta con el material de la cátedra) o **dudosa** (conviene confirmarla con el profe).

Para usarla, abrí `index.html` en el navegador o entrá por GitHub Pages. El banco de preguntas completo está en `datos/preguntas.json`.
